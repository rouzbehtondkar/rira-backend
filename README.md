# Vira Task — Employee Management gRPC Service

A small employee-management service built with C# and ASP.NET Core gRPC.

## Planned technology stack

- .NET 10 (LTS)
- ASP.NET Core gRPC
- Protocol Buffers
- Microsoft SQL Server
- Entity Framework Core
- Console application as a gRPC test client
- Unit and integration tests

## Scope

The service will support the following employee operations:

- Create an employee
- Get an employee by ID
- Update an employee
- Delete an employee

Employee fields:

- ID (generated by the server)
- First name
- Last name
- National code (unique)
- Birth date

## Repository structure

The solution structure and implementation details will be added incrementally as the design is finalized.

## Configuration and secrets

Connection strings and credentials must not be committed to this repository.

Use .NET User Secrets for local development configuration. Setup instructions will be added with the server project.
